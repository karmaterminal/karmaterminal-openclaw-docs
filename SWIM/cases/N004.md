# Case `N004` — fanoutMode `all` return (all-known-sessions recipient set)

**Family**: Routes
**Lifecycle status**: new
**Evidence class needed**: live-row, cross-seat
**Provenance**: RFC §6.8 fanout-mode contract; PR #551
**Registry version added**: v1

## Claim being proved

continue_delegate with `fanoutMode: "all"` resolves the recipient set to all-known-sessions on the host, and each recipient receives identical `traceparent`. Recipient set matches the live session enumeration at fanout time.

## Required minimum row shape

Snapshot the live session enumeration on the host. Fire delegate with `fanoutMode: "all"`. Verify every enumerated session received the return payload with shared `traceparent`. Verify no session was skipped and no non-session received the payload.

## Evidence surface(s)

Pre-fanout session enumeration snapshot; per-session jsonl trajectories; trace-tree query for shared `traceparent`; cross-seat agreement on recipient set.
