# Case `N009` — request_compaction failure path (`[system:compaction-failed]` system event + staged-delegate residue)

**Family**: Recovery
**Lifecycle status**: new
**Evidence class needed**: live-row
**Provenance**: RFC §4.2 volitional-compaction failure semantics
**Registry version added**: v1

## Claim being proved

Failed or rejected background compaction does NOT arm cooldown; instead, the tool emits `[system:compaction-failed]` telling the agent that evacuated state was not compacted AND staged post-compaction delegates remain pending.

## Required minimum row shape

Stage post-compaction delegates. Force compaction failure (provider error, auth fail, or controlled rejection). Verify cooldown NOT armed (subsequent request not blocked). Verify `[system:compaction-failed]` system event emitted. Verify staged delegates remain pending in TaskFlow.

## Evidence surface(s)

Tool call result with failure mode; cooldown state pre/post; system event log; TaskFlow staged-delegate query.
